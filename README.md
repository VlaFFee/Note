# Notes & Photos — Forge 1.20.1 (47.3.0)

## Сборка через GitHub
1. Создай пустой репозиторий на GitHub.
2. Залей в него содержимое этой папки (корень репозитория = папка с `build.gradle`).
3. Открой вкладку **Actions** -> последний запуск **Build mod** -> внизу **Artifacts** -> `notesmod-jar`.
4. Из архива достань `notesmod-1.0.0.jar` и положи в `mods` (Forge 1.20.1).

## Локально
Нужны Java 17 и Gradle 8.1.x: `gradle runClient` / `gradle build`.

## Анимации и звук
* Плавное открытие/закрытие: лист выезжает слева, текст справа сдвигается и проявляется, фото «падает» на стол. Прокрутка текста плавная.
* Звуки сгенерированы и лежат в `assets/notesmod/sounds/*.ogg` (шорох бумаги, скольжение фото, карандаш при сохранении, щелчок выбора) + тихая фоновая атмосфера, которая плавно нарастает и затухает.
  Хочешь свои — просто замени .ogg с теми же именами (моно, 44.1 кГц).
* На листе слева тоже виден текст заметки (мелкий, бледный, «рукописный»); не влезает — обрезается на «...».

## Использование
* Предметы «Записка» и «Фотография» — во вкладке креатива «Записки и фото». Рецептов нет.
* ПКМ по записке — окно; справа текст с прокруткой. В креативе есть «Редактировать»
  (метка, заголовок/дата, текст, фото). Сохранение принимает сервер только от креатив-игрока.
* ПКМ по фотографии — просмотр с поворотом/перекосом. В креативе внизу «Фото...».
* Папка фото: `<папка игры>/notes_photos` (создаётся сама). Форматы: png, jpg, bmp, gif.
  Фото стилизуются автоматически — см. `PhotoCache.process`.

В предмете хранится только имя файла, поэтому в мультиплеере у каждого игрока должны лежать одинаковые картинки.
